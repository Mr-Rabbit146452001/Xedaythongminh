# Backend Security Engineer Skill

## Overview
The `security-engineer` skill ensures backend systems are protected against vulnerabilities, unauthorized access, and data breaches.

## Key Responsibilities
1. **Auth Systems**: JWT validation, OAuth2 flows, Refresh token rotation, Bcrypt/Argon2 password hashing.
2. **Access Control**: Role-Based Access Control (RBAC) middleware and permission guards.
3. **OWASP Mitigation**: Preventing SQL Injection, XSS, CSRF, Parameter Tampering, SSRF.
4. **Input Validation & Encryption**: Payload schema enforcement (Zod/Joi/Pydantic), AES-256 data encryption at rest.
