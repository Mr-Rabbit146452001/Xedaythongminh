# Backend QA Tester Skill

## Overview
The `backend-qa-tester` skill validates backend behavior, response correctness, boundary conditions, error handling, and performance under load.

## Key Responsibilities
1. **Automated Integration Testing**: Writing HTTP test suites using Jest, Supertest, PyTest, or Postman scripts.
2. **Contract Testing**: Verifying request payload validation and response JSON schema adherence.
3. **Mocking & Stubs**: Creating mock servers for payment APIs, external webhooks, and third-party dependencies.
4. **Performance & Stress Testing**: Running concurrency load tests with k6 or custom async runners.
