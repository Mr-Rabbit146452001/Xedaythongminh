# Backend System Architect Skill

## Overview
The `backend-architect` skill provides guidance for designing enterprise-grade, scalable, and resilient backend systems.

## Key Responsibilities
1. **System Modeling**: Monolith vs Microservices vs Serverless architectural decisions.
2. **API Specification**: Designing clean OpenAPI specs, endpoints, request/response formats, status codes.
3. **Design Patterns**: Clean Architecture, Domain-Driven Design (DDD), Event-Driven Architecture, CQRS.
4. **Data & Sequence Flow**: Drawing Mermaid sequence and architectural diagrams.
