# Backend Developer Skill

## Overview
The `backend-developer` skill handles building server application logic, controllers, services, middleware, and external service integrations.

## Key Responsibilities
1. **API Development**: Express, NestJS, FastAPI, Flask, Spring Boot or Go handlers.
2. **Business Logic**: Core domain features, transaction handling, error response formatting.
3. **Integrations**: Payment gateways (Stripe, VNPay, Mock Bank), Webhooks, S3, Email/SMS notifications.
4. **Asynchronous Tasks**: Background job processing with BullMQ, Celery, or RabbitMQ.
