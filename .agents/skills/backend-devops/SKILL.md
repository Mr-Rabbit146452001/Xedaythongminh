# Backend DevOps Engineer Skill

## Overview
The `backend-devops` skill manages infrastructure deployment, server environments, runtime startup scripts, and container orchestration.

## Key Responsibilities
1. **Containerization**: Writing efficient, multi-stage `Dockerfile` and `docker-compose.yml` configs.
2. **Environment & Scripting**: Managing node/python startup scripts (`start_all.js`, batch/bash scripts).
3. **Tunneling & Networking**: Reverse proxies (Nginx), Ngrok HTTPS tunnels, CORS headers, port forwarding.
4. **CI/CD & Monitoring**: Setting up GitHub Actions, health check endpoints, PM2 process management, log rotation.
