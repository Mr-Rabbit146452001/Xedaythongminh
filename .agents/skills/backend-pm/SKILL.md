# Backend Product Manager Skill

## Overview
The `backend-pm` skill converts broad user goals into structured, actionable engineering tasks and orchestrates agent execution.

## Key Responsibilities
1. **Requirements Gathering**: Translating user requests into user stories, technical specs, and acceptance criteria.
2. **Dependency Mapping**: Coordinating sequence between DB changes, API development, Auth, QA, and Deployment.
3. **Workflow Orchestration**: Directing the flow between Architect ➔ DB ➔ Dev ➔ Security ➔ QA ➔ DevOps.
4. **Delivery Verification**: Ensuring overall output satisfies initial business requirements without regressions.
