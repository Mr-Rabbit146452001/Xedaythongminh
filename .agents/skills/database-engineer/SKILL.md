# Database Specialist Skill

## Overview
The `database-engineer` skill focuses on data persistence, relational data modeling, query optimization, and caching strategies.

## Key Responsibilities
1. **Schema Design**: Tables, relationships, foreign keys, constraints, and data normalization.
2. **Migrations**: Incremental SQL migration scripts (`.sql`) and ORM setup.
3. **Performance Tuning**: Index creation, execution plan analysis (`EXPLAIN ANALYZE`), connection pooling.
4. **Caching Layer**: Redis data structures (Hashes, Sets, Pub/Sub, TTL).
